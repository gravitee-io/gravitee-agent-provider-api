# AGENTS.md

Guidance for AI coding agents working on `gravitee-agent-provider-api`.

## Project

Java library defining the contract between Gravitee and the `agent-provider` plugins (plugins that discover AI agents hosted on external platforms: Bedrock, Vertex AI, LangGraph, ...).

- `AgentProviderFactory`: plugin entry point, creates an `AgentProviderApi` from a JSON configuration.
- `AgentProviderApi`: `test()`, `discover()`, `fetch(ids)`, optional `start(id)` / `stop(id)`.
- `model/`: records and enums exchanged with the host (`AgentSnapshot`, `AgentRef`, `Capability`, ...).

## Build

- Java 21 (see `.sdkmanrc`), Maven, parent `io.gravitee:gravitee-parent`.
- Build and verify: `mvn clean install`.
- Formatting is enforced by `prettier-maven-plugin` (check fails the build). Fix with `mvn prettier:write`.
- Every source file needs the Apache 2.0 license header (copy it from an existing file).

## Code conventions

- This is a public API consumed by plugins: keep changes backward compatible. New methods on interfaces get a `default` implementation (optional operations throw `UnsupportedOperationException`).
- Optional features are advertised per agent through `AgentSnapshot.capabilities`, not through extra interfaces.
- Nullability uses JSpecify: mark optional fields `@Nullable`; collections are never `null` (records normalize them to empty in their compact constructor).
- Document every public type and method with Javadoc, including `@throws AgentProviderException` when the provider can fail.
- Keep the `README.md` contract table in sync with the API.

## Commit conventions

- Conventional Commits format: `type(scope): subject`.
- Subject must be lower-case.
- Header ≤ 72 characters.
- Commitlint runs in CI; >100 fails the build.
- Single-line subject, no `Co-Authored-By` trailer.

Releases and `CHANGELOG.md` are generated by semantic-release from commit messages: do not edit the version or changelog by hand.
